## PC版 Claude Code 用 Handoff ドキュメント

**制作日**: 2026年9月20日
**対象環境**: Windows PC（OpenWebUI 稼働）
**実装期間**: 7日間（段階的実装）
**テスト期間**: 3日間

---

## 📋 **実装のゴール**

Ej の複数事業（TheVintageSalon + airstobu + GoldenMUGI）の日々のオペレーションを、AI マネージャーとして統合管理。

```
毎朝：「今日のタスク」自動指示
日中：Facebook/Instagram 監視・レポート自動生成
週末：週別分析
月末：月別統合分析

このすべてのプロセスが NOTE 記事化される
```

## 🎯 **Core Functionality (5つの機能)**

### **機能1: 毎朝「今日のタスク」自動指示**

**実行時刻**: 朝 6:30（設定可能）
**実行環境**: PC で自動起動

#### データソース
- Gemini が読み込み：
  - Google Calendar（TheVintageSalon / airstobu / GoldenMUGI の予定）
  - Gmail（未返信メール、重要度順）
  - Facebook Messenger（新規メッセージ）

#### 出力フォーマット
```
【朝の指示書】2026年9月21日

【Ej の予定】
09:00-11:00：空き時間
13:00-15:00：TheVintageSalon コミュニティ管理
16:00-17:00：メール返信 3件

【推奨タスク】
① 今朝（09:00-10:30）：airstobu の広告パフォーマンス分析（自動レポート参照）
② 11:00-12:30：Facebook グループの新規質問への返信案（AI 生成）
③ 15:00-16:00：YouTube 素材チェック

【注意】
- Instagram Reels 広告：予算 5,000円、CPA が 5% 上昇（要確認）
- TheVintageSalon：新規メンバー 5人、オンボーディング案あり

これで OK？ 修正が必要な箇所を言ってください。
```

#### 実装詳細
- Gemini API: Calendar/Mail 読み込み
- Claude: 優先度判定・テキスト生成
- 出力先: Slack / メール（Ej が選択）

### **機能2: Facebook グループ・ページの監視**

**実行頻度**: 1日 4回（朝 9時、12時、15時、19時）
**監視対象**:
- ビンテージモーターホームファンクラブ（Facebook グループ）
- The Vintage Salon Mobile（Facebook ページ）

#### データ収集
```
各実行時に以下を取得：
- 新規投稿数
- コメント / リアクション数
- 未返信コメント
- 新規メンバー申請
- ページ エンゲージメント
```

#### AI による自動分析
```
Claude が以下を生成：
- 「返信が必要なコメント」の優先度リスト
- 新規メンバーへの「返信テンプレ」
- トレンドキーワード（何について質問が多いか）
```

#### 出力フォーマット
```
【Facebook 日次レポート】2026年9月21日 15:00

【グループ】ビンテージモーターホームファンクラブ
- 新規投稿: 4件
- コメント: 23件（未返信: 3件）
- 新規メンバー申請: 2件

【優先度リスト】
① 「3日前の修復質問」に返信があった（コメント 5件で討論化）
② 「オイル選択」について初心者からの質問
③ 新メンバー 2件のプロフィール確認

【返信テンプレ（生成済み）】
質問① への返信案: [テンプレ表示]
質問② への返信案: [テンプレ表示]

---

【ページ】The Vintage Salon Mobile
- ページ訪問: 340人
- リーチ: 890人
- エンゲージメント: 125件

【注記】
「乗り心地改善」について 3件の問い合わせ。
TheVintageSalon 有料記事の需要あり。
```

#### 実装詳細
- Facebook Graph API v18.0
- 定時実行: Windows Task Scheduler
- ローカル DB: ネタの蓄積用（SQLite）
- 出力先: Slack / Dashboard（Streamlit）

### **機能3: Instagram Reels 広告の自動分析**

**実行頻度**: 1日 1回（夜 20時）
**広告予算**: 月 5,000-10,000円
**監視対象**: airstobu + TheVintageSalon のリール広告

#### データ収集
```
Meta Business Suite API から自動取得：
- インプレッション
- クリック
- コンバージョン
- CPC / CPA
- 日別トレンド
```

#### AI による最適化提案
```
Claude が日々のレポートで以下を分析：
- 「今日の CPA が昨日より 5% 高い」→ 理由分析
- 「どのクリエイティブが最適か」
- 「予算配分の調整提案」（例：Salon に 40%, airstobu に 60%）
```

#### 出力フォーマット
```
【Instagram 広告日次分析】2026年9月21日

【本日の成績】
- インプレッション: 23,450
- クリック: 1,220（CTR: 5.2%）
- 獲得数: 12（CPA: 1,200円）
- 支出: 5,000円 / 月予算

【週次との比較】
- CPA: 昨週 1,000円 → 今週 1,200円（↑2.4%）
理由推測：iOS 17.5 のトラッキング変更？

【提案】
① airstobu のビデオを 3秒短くする（25→22秒）
   → 前周期で 8% エンゲージメント改善実績あり

② TheVintageSalon の「修復背景」クリエイティブをテスト
   → 50代-60代 男性層へのアピール率が高い可能性

③ 予算配分：Salon 35% / airstobu 65%（現状 40/60）
   → 昨日の CTR 差分から

【即座に実行】
- クリエイティブ更新予定ある？
- 予算配分の変更を承認しますか？
```

#### 実装詳細
- Meta Graph API (Instagram Ads Manager)
- Claude による CPA 分析・最適化提案
- 出力先: Slack / Dashboard
- 自動実行: Windows Task Scheduler

### **機能4: 週別・月別統合分析**

**実行頻度**:
- 週別: 毎週金曜 19:00
- 月別: 毎月末 20:00

#### 週別分析の内容
```
【金曜の戦略会議】2026年9月27日

【先週の成果サマリー】
- Facebook: グループ投稿 18件 / ページ エンゲージメント 890件
- Instagram 広告: CPA 1,200円 / 獲得 65件 / 支出 10,000円
- メール対応: 22件 / 平均返信時間 4時間

【トレンド分析】
- 「乗り心地」関連の問い合わせが +40%
- ビジュアル系（修復背景）の反応が +28%
- 50代-60代 男性からのコンバージョンが +15%

【来週への提案】
① ネタ: 「乗り心地改善」について NOTE 記事化
   Ej の経験談 + AI による整理で高品質記事に

② 戦略: リール広告で「修復背景」シリーズを増加
   → 現在のターゲット層にハマっている

③ コンテンツ: TheVintageSalon 有料記事「乗り心地 5つの工夫」
   Facebook グループの質問からネタが豊富
```

#### 月別分析の内容
```
【月末振り返り会議】2026年9月30日

【9月の成果】
- Facebook グループ: メンバー +12人、月間エンゲージメント 3,240件
- Instagram 広告: 月間支出 20,000円（予算内）/ 獲得 112件 / CPA 1,200円
- NOTE 記事: 4本公開（準備中の 2本含む）

【戦略の効果測定】
- 「修復背景」コンテンツ: 反応 +32%
- シルバー層（50代-60代）: コンバージョン +18%
- TheVintageSalon の有料会員: +8人

【10月の重点】
① PR TIMES: Salon / airstobu のプレス発表（10月開始）
② NOTE: 「AI マネージャー実装プロセス」記事化開始
③ 広告: 「修復背景」系クリエイティブを 60% に集中

【Ej からのコメント求む】
- 上記戦略で OK？
- 修正点は？
- 10月の優先度は？
```

#### 実装詳細
- Claude による統合分析
- 過去データから トレンド抽出
- Streamlit Dashboard での可視化
- Slack での自動送信

**NOTE への投稿予定**:
- 毎週日曜 19:00 に「今週のプロセス記事」自動生成
- 毎月末に「月間統合記事」自動生成

#### 毎週の記事パターン
```
【無料記事】「Facebook グループで見えた今週のトレンド」
- グループの質問から「乗り心地」が増加
- AI マネージャーが自動分類した結果
- それが来週の記事ネタになった話

【有料記事】「AI が発見した 50代-60代 男性の本当のニーズ」
- 広告データから見える購買心理
- 修復背景コンテンツが刺さる理由
- マーケティング的な分析

【プロセス記事】「毎朝のタスク指示システムの実装プロセス」
（実装初期 3週間は「失敗と修正」を毎週配信）
```

#### 月末の統合記事
```
【有料記事】「9月を AI マネージャーで回してわかったこと」
- 実際の工数削減数
- Facebook グループとライターが不要な理由
- シルバー層マーケティングの発見
- 10月のテスト項目

この記事自体が「AI マネージャーの価値証明」になる
```

#### 実装詳細
- Claude が記事案自動生成
- Ej が 5-10分で確認・修正
- NOTE へ自動投稿
- 同時に X / Facebook にも投稿

## ⚠️ **既知の注意点**

### 1. Gemini Calendar/Mail 連携が不安定な可能性
```
回避策:
- 最初は「テスト用の Google Calendar」で実施
- 本番切り替えは Week 2 で実行
- エラー時は「手動での Calendar 確認」にフォールバック
```

### 2. Facebook API の権限問題
```
事前に確認：
- Ej のアカウントに「グループ管理」権限があるか
- Meta Business Suite へのアクセス権限があるか
- 詳細分析が有効か
```

### 3. Instagram 広告 API のレート制限
```
対応：
- 1日 1回の実行に留める
- 複数回実行が必要な場合は API 契約アップグレード
```

### 4. OpenWebUI の負荷
```
Ej の懸念：「現在重い」
対応：
- 実装時に「軽量化パス」も並行実施
- バックグラウンド処理を別プロセスで実行
```
